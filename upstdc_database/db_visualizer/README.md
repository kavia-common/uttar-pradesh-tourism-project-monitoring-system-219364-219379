# simple-db-viewer (db_visualizer)

- Node: >= 18 (tested with v18.20.8)
- Module system: CommonJS (package.json "type": "commonjs")

Install:
- Deterministic: npm ci (if package-lock.json present)
- Otherwise: npm install (generates lockfile)

Start:
- npm start (binds to 0.0.0.0, port defaults to 3000)
- Optionally: source ./postgres.env (generated by ../startup.sh)

Troubleshooting:
- If you see "Cannot find module './lib/express'", ensure no custom NODE_PATH is set and that node_modules/express exists.
- Run: rm -rf node_modules && npm ci (or npm install) to reinstall.
